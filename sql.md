Q1. SQL Fundamentals

1. What is SQL ?

SQL (Structured Query Language) is a programming language used to communicate with relational
databases

It allows us to store, retrieve, insert, update, and delete data in a database.

SQL is a language that helps us to talk to a database and manage the data stored inside it.

Suppose we have an IPL database containing information about : 

1.Players
2.Teams
3.Matches
4.Runs
5.Wickets
6.Venues

Suppose you want to 

-> find the top 10 run scorers
-> find out how many matches CSK has won 
-> Update a player's information 
-> Delete an unwanted record
-> Insert a new match  

We use SQL to perform these operations.

Q2. What is Database? 

A Database is an organised collection of data that can be easily accessed, managed and 
updated.

Q3. What can we do using SQL? 
SQL commands are divided into 5 major categories.

DDL -> Data Definition Language -> Defines database structure
DML -> Data Manipulation Language -> Modifies data 
DQL -> Data Query Language -> Retrieves data
DCL ->  Data Control Language -> Manages permissions
TCL -> Transaction Control Language -> Manages Transaction 

DDL Table Operations 
1. CREATE TABLE 
2. ALTER TABLE 
3. DROP TABLE
4. Truncate Table 
5. Rename Table  

DML  Operations
1. Insert
2. Update
3. Delete
4. Insert into select

DQL  Opeartions 

1. Select
2. Distinct
3. WHERE
4. ORDER BY
5. LIMIT
6. OFFSET
7. AS

DCL Opeartions

1. CREATE USER
2. ALTER USER
3. GRANT
4. REVOKE
5. Database ownership
6. user permissions

TCL Operations

1. BEGIN
2. COMMIT
3. ROLLBACK
4. SAVEPOINT
